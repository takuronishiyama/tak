# 🏎️ グランプリ物語

カイロソフト風のドット絵テイストで遊ぶ、**F1チーム運営シミュレーションゲーム**です。
弱小チームのオーナーとなり、マシンを開発し、ドライバーを育て、世界の頂点を目指します。

ビルド不要。ブラウザで開くだけで遊べます。

チーム運営はそのままに、週末だけがラリーになる**ラリー版（WRC）**も入っています。
チームを立ち上げるときに「🏎️ グランプリ／🏁 ラリー」で選びます（→ [ラリー版](#-ラリー版wrc)）。

## ▶ 遊びかた（いちばん簡単）

**[`grandprix.html`](grandprix.html) をダウンロードして開くだけです。**

CSS も JavaScript も全部入りの1ファイルなので、フォルダごと保存する必要がありません。
iPhone や iPad でも、このファイル1つをダウンロードして開けばそのまま遊べます。

> `index.html` のほうは `assets/` と `src/` のフォルダが揃っていないと動きません。
> ファイル1つだけ保存すると真っ白な画面になるので、その場合は `grandprix.html` を使ってください。

## リポジトリごと使う場合

```
git clone <this repo>
cd tak
open index.html          # macOS
# xdg-open index.html    # Linux
# start index.html       # Windows
```

`src/` を編集したら `node build.js` で `grandprix.html` を作り直せます。

## 📱 iPhone で遊ぶ

PWA なので、**ホーム画面に追加すればアプリとして起動します**（全画面・オフライン対応）。
ただし Service Worker は `https`（または `localhost`）でしか動かないため、
ファイルを直接開くのではなく配信する必要があります。

```
# 手元で試す（同じLAN内のiPhoneからアクセスできる）
python3 -m http.server 8000
# → iPhone の Safari で http://<PCのIPアドレス>:8000/ を開く
```

公開するなら GitHub Pages が手軽です（Settings → Pages → ブランチを選ぶだけ）。

Safari で開いたら **共有ボタン → 「ホーム画面に追加」**。
アイコンから起動すると Safari の UI が消え、ノッチとホームインジケータを避けた
全画面表示になります。一度起動すれば機内モードでも遊べます。

### App Store に出す場合

PWA のまま [Capacitor](https://capacitorjs.com/) で包めば、コードはそのままで
ネイティブアプリになります。

```
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/ios
npx cap init "グランプリ物語" com.example.gpmonogatari --web-dir=.
npx cap add ios
npx cap sync
npx cap open ios      # Xcode が開くので、署名して実機・App Store へ
```

`--web-dir=.` はこのリポジトリのルートがそのまま Web ルートだからです。
ビルド工程がないので、`npx cap sync` すれば変更が即反映されます。
（実機ビルドと App Store 申請には Mac と Apple Developer Program が必要です）

### 1週 = 1コマンド

1シーズンは**全12戦**。準備週にはコマンドを1つ選び、選ぶと1週が経過します。
次のレースまでに何回使えるかは、**移動の距離で変わります**。
同じ地域の連戦なら1回、隣の地域へ飛ぶなら2〜3回、大陸をまたげば3〜4回。
年の合計は36回で、開幕前の準備は4回です。残り回数は画面上部と次戦カードに ■ で出ます。

シーズンの折り返しには**サマーブレイク**が2週入ります。工場ごと閉まるので走ることも作ることもできず、

| コマンド | 内容 |
|---|---|
| 🗣️ **相談** | 首脳陣4人に、いま何が起きているかを聞く。開発責任者は「今週どこに使うか」まで言う。週は使わない |
| 🏎️ **開発** | 4つの部屋への入口。🖊️設計室（方針・ひらめき・技術）、🏭工房（パーツを作る）、🔬研究所（扇を調べて知見を溜める）が1週ずつ。🔧ガレージ（載せ替え・まとめ上げ）は週を使わない |
| 🛠️ **整備** | パーツのコンディションを回復し、信頼性（＝完走率）を戻す |
| 🧑‍✈️ **ドライバー** | 練習で4能力を鍛える／スキル特訓／スタッフの研修。契約とリザーブ、下部組織の育成もここ |

### レースウィーク

1. **作戦**。ドライバーごとに 🛡️安全第一／⚖️バランス／🔥攻める を選び、スタートタイヤ、
   タイヤの担当範囲、予選でのタイヤの使いかた、ピットの回数、パワーユニットの出力モード（温存／標準／全開）を決めます。
2. **フリー走行（金曜）**。履くタイヤの組みかた（予選重視／バランス／レース重視）と、走行時間を何に使うか
   （セットアップ／若手を乗せる／タイヤを試す／走らずに残す／ロングラン）を1つずつ選びます。
   金曜に履いたタイヤのことだけが、日曜にはっきり分かります。
3. **ブリーフィング**。ドライバーの言い分（「ブレーキを残すとリアが出る」）に、セッティングを変える／腕で何とかしろ／データを見せる、
   のどれで返すかを決めます。決まれば信頼が上がり、外せば下がります。
4. **予選**。Q1 で下位5台、Q2 でさらに5台が落ち、残った12台がポールを争います。
5. **グリッド**。パドックを歩いて、ドライバーや他チームの人と話せます。済ませてから決勝へ。
6. **決勝**。スタートシグナルが消えて発進。ドット絵のマシンがコースを周回し、オーバーテイク、ピットイン、
   トラックリミット、セーフティカー、リタイアが実況と無線で流れます。
   再生速度は 🐢じっくり／▶すこし速く／▶▶速く／▶▶▶とばす／⏱実時間 の5段階、
   カメラは 🎬おまかせ／🚩自チーム／🗺️全体／🎥オンボード／📺定点 の5つです。
7. **結果**。賞金・スポンサー収入・ファンと注目度の増減に加えて、
   1位と比べてどこで何秒負けたかのデブリーフィングと、その日の無線のやりとりが残ります。

## ゲームの仕組み

### パーツはアイテム

7つのカテゴリ（パワーユニット／エアロダイナミクス／ブレーキ／シャシー／サスペンション／ギアボックス／
エレクトロニクス）にそれぞれ1つパーツを装着します。パーツは
**名前・品質（並／良品／上物／特上／会心作）・器（性能の上限）・性能値・コンディション・素材** を持つ個別のアイテムです。

マシンの速さは **（車体の素の能力 ＋ パーツの合計）× インテグレート率** で決まります。
良い部品を集めるだけでは速くならず、1台の車に**まとめ上げる**ぶんが掛け算で効きます。
装着中のパーツから **最高速・コーナー・加速** の3性能が決まり、コースごとに求められる配分が違うため、
同じマシンでも得意・不得意が出ます。たとえば「グランデ・ロッソ」は最高速56%の超高速コース、
「モンテローザ市街地」はコーナー44%＋加速42%のストリートコースです。

**車を速くする場所は4つ**に分かれていて、場所ひとつに仕事ひとつです。

| 場所 | すること |
|---|---|
| 🖊️ **設計室** | この車の**方針**（ストレート重視／コーナー重視／加速重視／ドライバビリティ重視）を決める。抱えた**ひらめき**を図面に落とす。**技術**（高出力・高剛性・軽量化・高耐久・冷却強化、各5段）を積む |
| 🏭 **工房** | 新しいパーツを**作る**。品質は作った瞬間に決まり、それがそのまま器の大きさになる。**製造方針**（一点ものを作り込むか、予備シャシーも回すか）もここ |
| 🔧 **ガレージ** | 作ったパーツを**載せ替える**。外れたパーツは、いま載っているものに**吸わせる**と性能の45%を引き継ぐ。**まとめ上げ**（インテグレート）の寄せかたも決める。週は使わない |
| 🔬 **研究所** | 扇（空気と足／骨と制動／動力）を調べて**知見**を溜める。知見は 💡ひらめき（必ず会心作が出る設計）、⚡イノベーション（載せたままの個体を一段格上げ）、方針に逆らう向きの**上限を押し広げる**、の3つに使える |

いま積んでいるパーツを上限へ近づける**煮詰め**と、部品どうしの**つなぎ込み**は、工房と技術部門が**毎週ひとりでに進めます**。
速さは開発グループの厚みとファクトリー・風洞で決まります。あなたの出番は器の上限に届いたときで、
作り直すか、イノベーションか、施設を伸ばすかを決めます。

パーツの種類ごとに**製造ライン**が一本ずつあり、作った本数で段が上がります（間に合わせの台 → 専用の治具 → 一貫ライン → 無人ライン → 職人のライン）。
段が上がると品質の底と仕上がりの精度が上がり、扱える素材もスチールから複合材まで進みます。
あれこれ手を出すより、一つを作り続けたほうが同じ金で良いものが出ます。

### 信頼性というトレードオフ

パーツのコンディションは走るたびに減り、**リタイアしやすくなります**。
コンディションは性能の発揮率にも直結します。
徹夜で作業すればさらに減ります。1週を使って整備するか、次の週末まで我慢するか。ここが悩みどころです。

### 車体（マシン本体）

パーツとは別に、**車体そのものを1年かけて作り込みます**（扇の中のインテグレート）。

| 項目 | 効果 |
|---|---|
| 🧱 剛性 | コーナーで踏ん張る。壊れにくくなり、クラッシュも減る |
| 🪶 軽量化 | 最高速と加速。タイヤに優しくなり、スティントを引っぱれる |
| 🌬️ 空力コンセプト | コーナー。エアロパーツの効きが増し、前車を追いやすい |
| ❄️ 冷却 | 信頼性と回生。終盤にタレにくい |
| 🔋 バッテリー | 電気の容量と放電量。直線の仕掛けが決まりやすい |
| 🎯 ドライバビリティ | 車そのものは速くならないが、ドライバーが車の速さを出し切れる。合わないタイヤでも急にグリップが抜けない |
| 🧰 整備性 | ピット作業が速くなり、パーツの傷みも減って維持費が下がる |

方針に沿った項目はよく伸び、逆らう項目は**上限そのものが 58% で止まります**。
新型マシンを作ると上限は上がりますが車体は新造され、**前の車体の作り込みを50%引き継ぎます**。
煮詰めてから新車に移るか、早く新車に移るかの判断が生まれます。

### 📐 開発リソースの配分（シーズンをまたぐ判断）

開発画面の先頭で、**今季と来季にどう配分するか**を決めます。

| 方針 | 今季 | 来季 |
|---|---|---|
| 🔥 今季に全力 | 100% | 0% |
| ⚖️ 今季優先 | 88% | 20% |
| 🔀 半々 | 70% | 45% |
| 🌱 来季優先 | 48% | 75% |

来季に回したぶんは「🌱来季マシンの仕込み」として積み上がり、
**次に新型マシンを作ったときの初期性能**になります。

1シーズン（36手）を各方針で使った場合の実測：

| 方針 | 今季の伸び | 来季マシンの完成度 |
|---|---|---|
| 🔥 今季に全力 | +122 | 15% |
| ⚖️ 今季優先 | +108 | 33% |
| 🔀 半々 | +86 | 55% |
| 🌱 来季優先 | +59 | **82%** |

今季を捨てて来季に賭けるか、目の前の1勝を取りに行くか——実際のF1と同じ悩みです。
使わないまま年を跨ぐと仕込みは2割目減りします。

### マシンの世代

全パーツに共通の開発上限があり、装着中のパーツを上限まで煮詰めると、マシンは**自然と次の世代へ進みます**
（**MK-I → MK-II → … → MK-VI**。進み具合は設計室の「配分と世代」に出ます）。
世代が上がると開発上限と車体のベース性能が跳ね上がり、より大きな器のパーツを作れるようになります。
レース画面のマシンの見た目も、世代とともに大型ウイングやサイドポッドを備えた姿へと変わっていきます。

### 🛞 タイヤ

3種類のドライタイヤがあり、速さと保ちが逆になっています。

| タイヤ | ペース | 摩耗 | 寿命の目安 |
|---|---|---|---|
| 🔴 ソフト | 最速（-1.4%） | 1.60倍 | 15周 |
| 🟡 ミディアム | 標準 | 1.00倍 | 25周 |
| ⚪ ハード | -1.4%（遅い） | 0.66倍 | 38周 |

雨なら🟢インター、大雨なら🔵ウェットに自動で切り替わります。

週末に持ち込めるドライタイヤは **13セット（ハード2／ミディアム3／ソフト8）**、雨用はインター5・ウェット2の別枠です。
金曜に走らせたぶんは戻ってこないので、予選に全部注ぐか、日曜に新品を残すかを金曜に決めます。
タイヤには**作動域**があり、路面温度と走らせかたで芯の温度が動きます。
冷えたハードは働かず、熱いソフトは一気に減ります。フロントとリアは別に温まります。

**ドライレースでは2種類以上のタイヤを使わなければなりません**（実際のF1のルール）。
同じ銘柄だけで組まれた作戦は、いちばん短いスティントが自動で別銘柄に差し替わります。

**寿命を超えると急激にタレます**（超過周回数の2乗でタイムを失う）。
スタートタイヤは自分で選び、2本目以降は残り周回に合わせて自動で選ばれます。

ライバルは3通りの傾向（攻め／バランス／堅実）とストップ数を持つので、
**ソフトで3ストップの車と、ハードで1ストップの車が同じレースで戦います**。

レース中は全車のタイヤが順位表に表示されます（銘柄＋使用周回数、
寿命が近いと黄色、超えると赤く点滅）。自チームは残量バーつきで表示されます。
ピット作業中の車はピットレーンに停まり、順位表には `PIT` と出ます。

### 🔋 バッテリー（ERS）

**エレクトロニクス**の性能から、容量・1周あたりの回生量・放電量が決まります。
放電すると直線で速くなりますが、電気は無限ではありません。

- 通常走行では回生と放電がほぼ釣り合い、少しずつ減っていきます
- **前の車を2秒以内に捉えると、1.75倍の量を放電して仕掛けます**。
  攻め続けると5周ほどで空になり、そのぶんのタイムを失います
- ストレートの長いコースほど、放電が速さに変わりやすくなります

レース中は自チームのバッテリー残量がゲージで表示されます（残り少ないと赤）。

### 🤝 スポンサーの種類

スポンサーは**もらえるものが違います**。金額の大きさだけで選ぶものではありません。

| 種別 | 内容 |

### 📜 レギュレーション変更

**4シーズンに一度、マシンの規則が変わります。**

- パーツ・車体・マシン世代は**白紙から**（積んだ知見のぶんだけ、ゼロよりは良い所から）
- 施設・スタッフ・ファン・資金・オーナーのスキルは**そのまま**
- ライバルも同じだけ戻るので、上位と下位の差が一度リセットされる
- 供給を受けていたエンジンは新規則では使えなくなる
- **条文が2つ引かれ**、部位ごとの効きが変わる（例：燃料流量の上限 → パワー ×0.82、電装 ×1.14、ギア ×1.06）。全車に同じだけ効くので、違ってくるのは「どこに金をかければ速くなるか」
- 新しい規則を**読めたかどうか**がチームごとに決まり、読めたチームは開発が速く、外したチームは遅い。年を追うごとに差は縮む
- 規則が変わった直後は、設計室で車の方針を決め直せる

条文は全部で10条あり、規則期ごとに2つが選ばれます（グラウンドエフェクトの解禁、燃料流量の上限、可動ウイングの禁止、
最低重量の引き上げ、パワーユニットの開発凍結、ブレーキ素材の統一、タイヤウォーマーの禁止、電動出力の引き上げ、
ギアボックスの使用数制限、前後ウイングの幅の縮小）。ラリー版には別の10条があります。

チーム力は積み上がり続け、マシンだけが定期的に振り出しに戻ります。

### ⚔️ 追い抜きの攻防

0.55秒以内まで詰めると仕掛けます。コースの性格で戦い方が変わります。

- **ストレートで刺す** — 直線の長いコースで起きやすい。バッテリー残量とスリップストリームが効く
- **コーナーで飛び込む** — 腕とマシンのコーナー性能がものを言う。失敗すると**コースを外れかけてタイムを失い、タイヤも傷む**
- **守る** — 「勝負強い」ドライバーは簡単には譲らない

抜きやすさはコースで大きく変わります（計測値：市街地 26.7回／レース ↔ 高原 68.5回／レース）。

### 🔌 パワーユニットの供給

| 場所 | 入ると |
|---|---|
| 🏎️ 自チームのガレージ | ガレージ（載せ替え・まとめ上げ） |
| 🧑‍✈️ ドライバーの控え | ドライバー |
| 📊 タイミングブース | 情報（順位・収支） |
| 🏁 コースへの出口 | レースへ向かう |

ガレージはチームごとに並び、自チームだけシャッターが開いて中で整備中の
マシンが見えます。ピットウォールのボードや屋根の帯は各チームの色です。

### 🎨 見た目（2種類）

トップバーの 🌙 / 🎨 ボタンで、いつでも切り替えられます（選択は保存されます）。

| | HD-2D（初期設定） | カイロ風 |
|---|---|---|
| 画面 | 暗い舞台に金の枠が浮かぶ | 生成りの紙にこげ茶の太枠 |
| コース図 | 夜の路面。セクター線が光る | 芝の上の見取り図 |
| レース | 光・ボケ・粒子つき | 素直なドット絵 |
| 本拠地 | 夕暮れ。窓に明かりが灯り、建物が影を落とす | 昼 |

**HD-2D側で足しているもの**（オクトパストラベラー風の絵作り）:

- **ブルーム** — 明るい所だけがにじんで光る。同じ絵を `multiply` で重ねて
  色を4乗し、暗い色を沈めてから、ぼかして加算している
- **被写界深度** — カメラが寄るほど、見ていない所がぼける。ジオラマらしさが出る
- **落ち影** — 建物や木のシルエットを黒くして、光の向きへずらして重ねる。
  形に沿った長い影になる
- **色調** — 影側を紫に沈め（`multiply`）、そのうえで明暗差を立てる（`overlay`）
- **粒子** — 火花・砂ぼこり・雨の水しぶき
- **周辺減光** — 四隅を落として中央に目を向けさせる

追加ライブラリは使っていません。canvas 2D の `filter` と合成モードだけです。
`filter` が使えない端末（Safari 14 未満など）では、拡大縮小のにじみで代用し、
落ち影と被写界深度は自動で省かれます。

### 🎬 レース観戦

再生速度は **🐢とてもゆっくり／▶ゆっくり／▶▶ふつう／▶▶▶はやい／⏱実時間** の5段階です。
**実時間**は実際のレースと同じ速さで進みます（24周でおよそ35〜40分）。

**カメラ**が3モードあります。

- 🎬 **おまかせ** — 自チームが誰かと2.2秒以内で競っていればそのバトルに寄り、
  いなければ首位争いを追う
- 🚩 **自チーム** — 自分の2台を収める
- 🗺️ **全体** — コース全体を俯瞰

寄ると車が大きく描かれ、コーナー名も読めるようになります。
最終ラップには **FINAL LAP**、ゴール時にはチェッカーフラッグが振られます。
ピット作業中はクルーが4輪に付き、残り時間がカウントダウンされます。

### 📝 契約更改

シーズンが明けると、**活躍した人ほど報酬を要求します**。
チームが大きく、順位が良く、ファンが多いほど要求は強くなります
（優勝チームで週の人件費 +22%、最下位で +12%）。

勝ち続けると維持費が重くなるので、**強くなっても経営から解放されません**。

### 🏆 チャンピオンシップ

配点は**実際のF1と同じ** 25-18-15-12-10-8-6-4-2-1 の10位まで。
さらに **10位以内で完走したファステストラップに +1点** が付きます
（10位より下だった場合はボーナスなし）。

「📖情報」を開くと、ドライバーズ／コンストラクターズの両ランキングに加え、
**優勝・表彰台・ポールポジション・ファステストラップの回数**、そして
**ラウンド別の獲得ポイント表**（金＝優勝、緑＝表彰台、× ＝リタイア）が見られます。

### 📣 注目度（メディア露出）

チームがどれだけ話題になっているかを表す 0〜100 の値です。

`🫥無名` → `📻注目され始め` → `📰話題のチーム` → `📺人気チーム` → `🌟主役` → `👑時代の顔`

**上位でゴールするほど上がります。ポイント圏外でも順位が上なら上がります。**

| できごと | 注目度 |
|---|---|
| 優勝 | +16 |
| 表彰台（3位） | +10 |
| 入賞（8位） | +5 |
| ポイント圏外（14位） | +1.8 |
| 最後方（20位） | +0.4 |
| ポールポジション | +3 |
| ファステストラップ | +3 |
| グリッドから順位を上げた | 1つにつき +0.4（最大 +6） |
| リタイア | -2 |

放っておくと毎週 3.5% ずつ風化するので、走り続けないと忘れられます。

注目度は経営に直結します。

- **スポンサー収入が最大 1.6倍** になります（注目度50で ×1.30、95で ×1.57）
- **大手スポンサーは注目度が条件**です。ファンを集めるだけでは相手にされません
- 注目度が高いほど、**向こうから契約のオファーが届く**ようになります。
  オファーには通常より多い契約金が付きますが、4週で引っ込みます

つまり、賞金の出ない11位でも「20位より11位」に価値があり、
最後方から追い上げた一戦がスポンサー契約につながります。

### 🎫 開発チケット

入賞できないレースが続くと、チームに**開発チケット**が届きます
（イージー3戦／ノーマル4戦／ハード5戦／ヘル6戦の連続ノーポイントで1枚）。
1枚使うと、設計室や工房の作業を**週を進めずに**1回行えます。金と研究ポイントはいつもどおり払います。
入賞するとカウントはリセットされます。

苦しいときほど手が止まるのがこの手のゲームの詰みどころなので、
沈んだチームに一手ぶんの余地を残すための仕組みです。

### 🎓 下部組織（ユースアカデミー）

施設の「ユースアカデミー」を持つと、若手を抱えて育てられます。

- 「👥人事」から**若手をスカウト**（アカデミーのレベルで枠が増える：Lv1で1人、Lv10で6人）
- 若手は**毎週すこしずつ成長**します。コマンドを消費しません
- 伸びは **才能★1〜5**（平凡／有望／逸材／天才肌／大器）とアカデミーのレベル、
  トレーナーの技能で決まります
- **21歳までが伸び盛り**。22〜23歳で鈍り、24歳を過ぎるとほぼ止まります
- トップチームのシートが空いていれば**昇格**させられます

アカデミーのレベル別に、1シーズン育てた場合の総合値の伸び（初期25から）：

| 才能 | Lv1 | Lv5 | Lv10 |
|---|---|---|---|
| ★1 平凡 | 34.9 | 43.7 | 55.7 |
| ★3 逸材 | 40.6 | 54.8 | 73.1 |
| ★5 大器 | 54.3 | 71.6 | 92.1 |

3年目の移籍市場に出る即戦力が総合65〜69なので、
**アカデミーに投資して大器を掘り当てれば、買うより強い**ドライバーが育ちます。

### 経営

毎週スタッフ・ドライバーの給料と施設維持費がかかります。

- **🏁 カート**。施設のカート場で、左右・アクセル・ブレーキの4つで自分で走るミニゲームです。

## 🏁 ラリー版（WRC）

チームを立ち上げるときに「🏁 ラリー」を選ぶと、同じチーム運営のまま週末だけがラリーになります。
本拠地・施設・人事・営業、それに開発の4つの部屋はそのまま。パーツの呼び名だけが現場のものに変わります
（エアロダイナミクスは「デフと旋回」に、パワーユニットは「エンジンと過給」に、ギアボックスは「トランスミッションと4WD」に）。
セーブはグランプリとは別に持ちます。

**走りかた。** サーキットと違って並んで走りません。1台ずつ間隔をあけて出て、SS（スペシャルステージ）ごとのタイムを足していきます。
抜くもブロックもなく、あるのは「自分のタイムをどれだけ削れるか」「削りにいって、どれだけ外さずにいられるか」の二つだけです。

**ラリーは13本**（モンテヴェルデ、スノーフィヨルド、シエラ・ロハ、コスタ・ヴェルデ、サバンナ・トレイル、レイクランド、オリーヴ・マウンテン、
ヴィーニャ・アスファルト、ヒノキ・フォレスト、ハイランド・グラベル、ミクスト・ソル、アンデス・コースト、ヴァインベルク）で、年ごとに入れ替わります。
路面は **グラベル／ターマック／スノー** の3つで、食いつき・壊れやすさ・走行順の損得がそれぞれ違います。
1戦は3日（たとえば 4本・6本・3本）に分かれ、同じ道を午前と午後に二度通り、二度目は路面が荒れます。夜のSSがあるラリーもあります。

**週末に決めることは3つ**です。

| 決めること | 内容 |
|---|---|
| 📓 レッキ（下見） | 行かない／一往復（900万、週は使わない）／二往復（1,800万、1週使う）。ペースノートの精度がここで決まる |
| ⚖️ 攻めかた | 🛡️確実に／⚖️標準／🔥攻める／💥振り切る。速いほど外す確率が上がり、振り切ると1本で終わることもある |
| 🛞 積むスペア | タイヤを何本持つか。パンクしたときの傷の深さが変わる |

**サービスパーク**は日の変わり目と二日目の真ん中に入り、使えるのは30分です。
点検だけ（5分）、タイヤ交換（6分）、足まわり（12分）、外まわり（9分）、駆動系（16分）、味つけ（8分）から選び、
超えた1分につき10秒が足されます。

**走行順**は、初日が選手権の順位の逆、二日目からは前日の順位の逆です。
グラベルの初日は前にいるほど砂利を掃いて損をし（先頭で最大1.2%）、二日目からは逆に得をします。ターマックではほとんど効きません。

**右席（コ・ドライバー）**が、ドライバーひとりに一人つきます。ペースノートの精度は、
素の0.52に右席の腕（最大+0.34）、レッキ（+0.20）、息の合いかた（+0.12）が乗ったものです。
息の合いかたは一緒に走ったラリーの数で育ち（1 − 0.9ⁿ）、組み替えると0に戻ります。
市場には長く組んできた右席を連れてくる人もいます。

SSで起きるのは、パンク、スピン、コースオフ、サスペンションの破損、エンジン、クラッシュの6つ。
最終SSは**パワーステージ**で、上位5台に 5-4-3-2-1 のおまけの点が入ります。
走行画面は 🗺️俯瞰／🎥後方／🚗車内／📺定点 の4つの見かたがあり、車は部品で見た目が育ちます。
技術規則の条文はラリー用に10条（吸気リストリクター、最低重量、アクティブデフ禁止、ハイブリッド義務化、ストローク上限、
アンチラグ禁止、アンダーガード、タイヤ銘柄の統一、安全装備、変速段数の制限）が別にあります。

### レースシミュレーションについて

全22台について1周ずつラップタイムを積み上げています。ラップタイムは
マシン性能60%＋ドライバー40%を基準に、タイヤ摩耗・終盤のスタミナ低下・
天候・作戦・ドライバースキル・ランダム要素で変動します。
前車と0.9秒以内に詰まると「ダーティエア」でタイムを失うため、
抜きにくいコースほど団子になり、順位が動きにくくなります。

観戦画面の車の位置は、この積み上げたタイムから逆算して描いています。
画面に映っているバトルは演出ではなく、実際に結果を決めている計算そのものです。

### コース形状が走りを決める

サーキットの形は座標の羅列ではなく、**解析されて実際のルールになります**。

`src/geom.js` がコース形状から曲率を求め、コーナーとストレートを自動で切り分けます。
そこから導かれるものが3つあります。

**1. 追い抜きやすさ** — 最長ストレートが1周に占める割合が、そのまま
ダーティエアの効きに反映されます。モンテローザ市街地（最長ストレート17%・11コーナー）は
実際に抜けず、グリーンヒル・フォレスト（45%）では順位がよく動きます。

**2. マシンごとの速度プロファイル** — 各車について
「コーナーでどこまで減速し、立ち上がりでどう加速し、直線でどこまで伸びるか」を
最高速・コーナー・加速の配分から計算します。同じラップタイムの2台でも、
ダウンフォース型はコーナーで、パワー型は直線で前に出るため、
**1周のあいだに何度も抜きつ抜かれつが起きます**。
高速域ではスピードライン、減速時にはブレーキランプが点きます。

**3. 区間タイム** — 1周は3つのセクターに分けられます（境界は 1/3・2/3 地点にいちばん近い
直線上に置かれます）。各セクターのタイムは、その車の速度プロファイルの配分から算出されるので、
**どのマシンがどの区間で速いのかがそのまま数字に出ます**。
ピットでの停止時間は最終セクターに加算されます。

観戦画面では実際のタイミングモニターのように、セッション最速は紫、自己ベストは緑で
表示されます。前の周のタイムは薄く残るので、3区間すべてを見比べられます。

**4. コースの描画** — コーナー区間には縁石が、最長ストレートには DRS 区間の表示が入り、
スタートラインの手前にはグリッド、その外側にピットレーンとガレージが並びます。
セクター境界には S1 / S2 / S3 の標識が立ち、曲率の急なコーナーにはそのコースの
名物コーナー名（オー・ルージュ、スプーンカーブ、カジノヘアピンなど）が表示されます。
コース外にはテーマに応じた景色が並びます（芝＝木立、市街地＝ビル、砂漠＝ヤシと岩、
ネオン＝電飾看板）。メインストレートのピット反対側には観客席が入ります。
スタート地点は各コースの最長ストレート上に来るよう配置してあります。

レース開始時にはスタートシグナルが5つ順に点灯し、消灯と同時にスタート。
再生速度は「じっくり（約95秒）／ふつう（約40秒）／はやい（約13秒）」から選べます。
ガレージのコース図もセクターごとに色分けされ、名物コーナーの位置が示されます。

ライバルチームもマシンの型を持っています（パワー型・ダウンフォース型など）。
コースとの相性で速さが変わるので、毎戦おなじ顔ぶれが前にいるわけではありません。

### UI・UX・オブジェクトの作り込み

いまの絵はすべて Canvas への手描き（`src/base.js` `src/paddock.js`
`src/grid.js` `src/interior.js` `src/raceview.js`）で、
ドット絵の質感を CSS と描画コードで作っている。
ここを作り込むにあたって、Unreal Engine を「絵を作る側」として
使うことはできる。UE 5 には公式のブラウザ書き出しがないため
（HTML5 書き出しは UE 4.24 で外れた）、ゲームそのものを UE で
動かすとブラウザと PWA での配布を捨てることになる。

現実的な進めかたは3つ。

1. **UE をアセット工場として使う**（おすすめ）。マシン・建物・人物を
   UE 側でモデリングしてライティングを当て、正射影で複数アングルの
   スプライトや背景を書き出し、いまのゲームにそのまま差し込む。
   オクトパストラベラー風の見た目とも相性が良く、配布形態は変わらない。
   ゲーム側は「描画をコードから画像に差し替える」だけで済むよう、
   描画関数を1か所にまとめておく必要がある。
2. **ネイティブアプリとして作り直す。** 見た目の自由度はいちばん高いが、
   ゲームロジック（`src/state.js` `src/race.js`）以外は書き直しになる。
3. **ウェブのまま 3D 表現を足す。** three.js などで観戦画面だけ立体にする。
   配布は変わらないが、UE の資産は直接は使えない。
