# 🏎️ グランプリ物語

カイロソフト風のドット絵テイストで遊ぶ、**F1チーム運営シミュレーションゲーム**です。
弱小チームのオーナーとなり、マシンを開発し、ドライバーを育て、世界の頂点を目指します。

ビルド不要。`index.html` をブラウザで開くだけで遊べます。

```
git clone <this repo>
cd tak
open index.html          # macOS
# xdg-open index.html    # Linux
# start index.html       # Windows
```

## 遊びかた

### 1週 = 1コマンド

1シーズンは **48週 / 全12戦**。3週の準備期間ごとにレースがやってきます。
準備週にはコマンドを1つ選び、選ぶと1週が経過します。

| コマンド | 内容 |
|---|---|
| 🔧 **開発** | パーツのレベルを上げる。資金と研究ポイントを消費。12%で「ひらめき」大成功 |
| 🔬 **研究** | 研究ポイントを稼ぐ／貯めた研究Pで**新設計（開発上限の解放）** |
| 🛠️ **整備** | パーツのコンディションを回復し、信頼性（＝完走率）を戻す |
| 💪 **練習** | ドライバーの「速さ・技術・体力・精神」を鍛える |
| 📣 **営業** | プロモーションでファン獲得／新規スポンサーと契約 |
| ☕ **休養** | 全員のコンディションを回復 |

週を消費しない自由メニューとして **🏗️施設** / **👥人事** / **📖情報（セーブ）** があります。

### レースウィーク

1. **作戦を決める** — ドライバーごとに 🛡️安全第一 / ⚖️バランス / 🔥攻める を選択
   （攻めるほど速いが、リタイアとタイヤ消耗のリスクが上がる）
2. **予選** — マシン性能とドライバーの腕でグリッドが決まる
3. **決勝** — ドット絵のマシンがコースを周回。オーバーテイク、ピットイン、
   トラブルによるリタイアが実況ログに流れる（等速／倍速／超速／結果へ）
4. **結果** — 賞金・スポンサー収入・ファンの増減

## ゲームの仕組み

### マシン性能

5つのパーツ（パワーユニット／エアロダイナミクス／シャシー／サスペンション／
エレクトロニクス）のレベルから、**最高速・コーナー・加速** の3つの性能が決まります。

コースごとに求められる性能の配分が違うため、同じマシンでも得意・不得意が出ます。
たとえば「グランデ・ロッソ」は最高速56%の超高速コース、
「モンテローザ市街地」はコーナー44%＋加速42%のストリートコースです。

### 信頼性というトレードオフ

開発するとパーツのコンディションが下がり、**リタイアしやすくなります**。
速さを求めて開発を続けるか、1週を使って整備するか——ここが悩みどころです。

### 設計ティア

パーツごとに開発上限があります。上限に達したら「研究」で
マークI → マークII → … → ゼロシリーズ と**新設計を解放**して、さらに上を目指します。

### ドライバー

- **速さ / 技術 / 体力 / 精神** の4能力と、`雨マスター` `予選番長` `スタート職人` などの**個性**
- レースと練習で経験値が貯まり、レベルアップで全能力が伸びる
- 調子（コンディション）は週ごとに変動し、レースの結果に影響する
- 34歳を超えると衰えはじめ、38歳以降は引退することも

### 経営

毎週スタッフ・ドライバーの給料と施設維持費がかかります。
収入源はレースの賞金とスポンサー。ファンが増えるほど大口のスポンサーと契約できます。
資金がマイナス2万を割り込むとチーム解散＝ゲームオーバーです。

### シーズン

全12戦を終えるとコンストラクターズ順位に応じた賞金が入り、次のシーズンへ。
ライバルチームも毎年強化されるので、開発の手を緩めると置いていかれます。

## 技術メモ

ビルドツールもフレームワークも使っていません。素の HTML / CSS / JavaScript です。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨格 |
| `assets/style.css` | カイロソフト風のスタイル（太いこげ茶の枠 × 生成りの紙 × 原色） |
| `src/data.js` | サーキット・パーツ・スポンサー・ライバルなどのゲームデータ |
| `src/state.js` | ゲーム状態、性能計算、セーブ／ロード |
| `src/race.js` | 予選・決勝のシミュレーション（ラップ単位でタイムを積み上げる） |
| `src/raceview.js` | レース観戦画面（Canvasでの描画とアニメーション） |
| `src/ui.js` | 画面描画 |
| `src/main.js` | 週の進行と各コマンド |

セーブデータはブラウザの `localStorage` に自動保存されます
（「情報」→「最初から」で消去できます）。

### レースシミュレーションについて

全22台について1周ずつラップタイムを積み上げています。ラップタイムは
マシン性能60%＋ドライバー40%を基準に、タイヤ摩耗・終盤のスタミナ低下・
天候・作戦・ランダム要素で変動します。
前車と0.9秒以内に詰まると「ダーティエア」でタイムを失うため、
抜きにくいコースほど団子になり、順位が動きにくくなります。

観戦画面の車の位置は、この積み上げたタイムから逆算して描いています。
画面に映っているバトルは演出ではなく、実際に結果を決めている計算そのものです。
