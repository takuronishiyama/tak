# 🏎️ グランプリ物語

カイロソフト風のドット絵テイストで遊ぶ、**F1チーム運営シミュレーションゲーム**です。
弱小チームのオーナーとなり、マシンを開発し、ドライバーを育て、世界の頂点を目指します。

ビルド不要。ブラウザで開くだけで遊べます。

## ▶ 遊びかた（いちばん簡単）

**[`grandprix.html`](grandprix.html) をダウンロードして開くだけです。**

CSS も JavaScript も全部入りの1ファイルなので、フォルダごと保存する必要がありません。
iPhone や iPad でも、このファイル1つをダウンロードして開けばそのまま遊べます。

> `index.html` のほうは `assets/` と `src/` のフォルダが揃っていないと動きません。
> ファイル1つだけ保存すると真っ白な画面になるので、その場合は `grandprix.html` を使ってください。

## リポジトリごと使う場合

```
git clone <this repo>
cd tak
open index.html          # macOS
# xdg-open index.html    # Linux
# start index.html       # Windows
```

`src/` を編集したら `node build.js` で `grandprix.html` を作り直せます。

## 📱 iPhone で遊ぶ

PWA なので、**ホーム画面に追加すればアプリとして起動します**（全画面・オフライン対応）。
ただし Service Worker は `https`（または `localhost`）でしか動かないため、
ファイルを直接開くのではなく配信する必要があります。

```
# 手元で試す（同じLAN内のiPhoneからアクセスできる）
python3 -m http.server 8000
# → iPhone の Safari で http://<PCのIPアドレス>:8000/ を開く
```

公開するなら GitHub Pages が手軽です（Settings → Pages → ブランチを選ぶだけ）。

Safari で開いたら **共有ボタン → 「ホーム画面に追加」**。
アイコンから起動すると Safari の UI が消え、ノッチとホームインジケータを避けた
全画面表示になります。一度起動すれば機内モードでも遊べます。

### App Store に出す場合

PWA のまま [Capacitor](https://capacitorjs.com/) で包めば、コードはそのままで
ネイティブアプリになります。

```
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/ios
npx cap init "グランプリ物語" com.example.gpmonogatari --web-dir=.
npx cap add ios
npx cap sync
npx cap open ios      # Xcode が開くので、署名して実機・App Store へ
```

`--web-dir=.` はこのリポジトリのルートがそのまま Web ルートだからです。
ビルド工程がないので、`npx cap sync` すれば変更が即反映されます。
（実機ビルドと App Store 申請には Mac と Apple Developer Program が必要です）

### 1週 = 1コマンド

1シーズンは **48週 / 全12戦**。3週の準備期間ごとにレースがやってきます。
準備週にはコマンドを1つ選び、選ぶと1週が経過します。

**次のレースまでに何回コマンドを使えるか**は、画面上部と次戦カードに
残り回数ぶんの ■ で表示されます。

| コマンド | 内容 |
|---|---|
| 🔧 **開発** | 装着中パーツを**改良**する／**新しいパーツを設計**する。12%で「ひらめき」大成功 |
| 🔬 **研究** | 研究ポイントを稼ぐ／**新型マシンを開発**する |
| 🛠️ **整備** | パーツのコンディションを回復し、信頼性（＝完走率）を戻す |
| 💪 **練習** | ドライバーの4能力を鍛える／**スキル特訓**で新スキルを習得させる |
| 📣 **営業** | プロモーションでファン獲得／新規スポンサーと契約 |
| ☕ **休養** | 全員のコンディションを回復 |

週を消費しない自由メニューとして **🏎️マシン（装着・合成）** / **🏗️施設** / **👥人事** /
**📖情報（セーブ）** があります。

### レースウィーク

1. **作戦とタイヤを決める** — ドライバーごとに 🛡️安全第一 / ⚖️バランス / 🔥攻める を選び、
   さらに**スタートタイヤ**を選ぶ（攻めるほど速いが、リタイアとタイヤ消耗のリスクが上がる）
2. **予選** — マシン性能とドライバーの腕でグリッドが決まる
3. **決勝** — スタートシグナルが消えて発進。ドット絵のマシンがコースを周回し、
   オーバーテイク、ピットイン、トラブルによるリタイアが実況ログに流れる。
   区間タイムと全車のタイヤがリアルタイムで更新される
   （🐢とてもゆっくり／▶ゆっくり／▶▶ふつう／▶▶▶はやい／結果へ。既定は「ゆっくり」）
4. **結果** — 賞金・スポンサー収入・ファンと注目度の増減

## ゲームの仕組み

### パーツはアイテム

5つのカテゴリ（パワーユニット／エアロダイナミクス／シャシー／サスペンション／
エレクトロニクス）にそれぞれ1つパーツを装着します。パーツは
**名前・レアリティ★1〜5・性能値・コンディション** を持つ個別のアイテムです。

装着中の5つのパーツから **最高速・コーナー・加速** の3性能が決まり、
コースごとに求められる配分が違うため、同じマシンでも得意・不得意が出ます。
たとえば「グランデ・ロッソ」は最高速56%の超高速コース、
「モンテローザ市街地」はコーナー44%＋加速42%のストリートコースです。

**パーツの入手と育成**

| 手段 | 内容 |
|---|---|
| **改良**（開発コマンド） | 装着中パーツの性能を伸ばす。上限まで |
| **設計**（開発コマンド） | 新しいパーツを1つ作る。レアリティは抽選 |
| **合成**（マシンメニュー） | 素材パーツを吸収させ、性能+45%分・**レアリティ上昇**・追加効果の継承を狙う |

レアリティは**改良の上限**に効きます（★1は世代の上限ちょうど、★5なら上限の148%まで）。
できたてのレアパーツは弱くても、育てれば装着中のパーツを追い抜きます。
`🪶軽量化` `🛡️高耐久` `❄️冷却強化` `💠高剛性` `🔥高出力` といった
**追加効果**が付くこともあり、合成で引き継げます。

### 信頼性というトレードオフ

改良するとパーツのコンディションが下がり、**リタイアしやすくなります**。
コンディションは性能の発揮率にも直結します。
速さを求めて開発を続けるか、1週を使って整備するか——ここが悩みどころです。

### 車体（マシン本体）

パーツとは別に、**車体そのものを1年かけて熟成させます**。

| 項目 | 効果 |
|---|---|
| 🧱 剛性 | コーナー性能と信頼性 |
| 🪶 軽量化 | 最高速と加速 |
| 🌬️ 空力コンセプト | コーナー性能＋**エアロパーツの効果を底上げ** |
| ❄️ 冷却 | 信頼性＋**バッテリーの回生量** |

1手あたりの伸びはパーツ改良より小さいぶん、信頼性・ERS・エアロの効きまで広く効きます。
新型マシンを作ると上限は上がりますが車体は新造され、**前の車体の熟成度を50%引き継ぎます**。
煮詰めてから新車に移るか、早く新車に移るかの判断が生まれます。

### 📐 開発リソースの配分（シーズンをまたぐ判断）

開発画面の先頭で、**今季と来季にどう配分するか**を決めます。

| 方針 | 今季 | 来季 |
|---|---|---|
| 🔥 今季に全力 | 100% | 0% |
| ⚖️ 今季優先 | 88% | 20% |
| 🔀 半々 | 70% | 45% |
| 🌱 来季優先 | 48% | 75% |

来季に回したぶんは「🌱来季マシンの仕込み」として積み上がり、
**次に新型マシンを作ったときの初期性能**になります。

1シーズン（36手）を各方針で使った場合の実測：

| 方針 | 今季の伸び | 来季マシンの完成度 |
|---|---|---|
| 🔥 今季に全力 | +122 | 15% |
| ⚖️ 今季優先 | +108 | 33% |
| 🔀 半々 | +86 | 55% |
| 🌱 来季優先 | +59 | **82%** |

今季を捨てて来季に賭けるか、目の前の1勝を取りに行くか——実際のF1と同じ悩みです。
使わないまま年を跨ぐと仕込みは2割目減りします。

### マシンの世代

全パーツに共通の開発上限があり、上限に達したら「研究」で
**新型マシン MK-I → MK-II → … → MK-VI** を開発します。
世代が上がると開発上限と車体のベース性能が跳ね上がり、より高性能なパーツを設計できるように
なります。レース画面のマシンの見た目も、世代とともに大型ウイングやサイドポッドを備えた
姿へと変わっていきます。

### ドライバーとスキル

- **速さ / 技術 / 体力 / 精神** の4能力
- ドット絵の顔・国籍・**性格**を持ち、一人ひとり違う
- **スキル**を最大5つまで習得。レベルアップで閃くほか、「練習」→スキル特訓でも習得できる
- レースと練習で経験値が貯まり、レベルアップで全能力が伸びる
- 調子（コンディション）は週ごとに変動し、レースの結果に影響する
- 34歳を超えると衰えはじめ、38歳以降は引退することも

**性格**は飾りではなく、すべて数値に効きます。
レース後には性格に応じたひとことを残すので、チームの空気が伝わってきます。

| 性格 | 効果 |
|---|---|
| 🔥 熱血漢 | 結果に感情が乗る。勝てば絶好調、負ければ大きく落ち込む |
| 🧊 クール | 結果に左右されず、調子がほとんど動かない |
| 🔧 職人肌 | マシンへの要求が的確で、**開発の伸びが上がる** |
| ☀️ ムードメーカー | 休養での回復が大きく、悪い結果を引きずらない |
| 👑 負けず嫌い | 表彰台なら絶好調、圏外だと荒れる。練習熱心 |
| 📚 努力家 | **練習の効果が高い**。落ち込みにくい |
| ⚡ 荒くれ | 調子の波が激しい |

スキルはすべてレース計算に実際に接続されています。

| スキル | 効果 |
|---|---|
| 🌧️ 雨の魔術師 | 雨・大雨で速さ +18% |
| 🚀 スタートダッシュ | 1周目のグリッド差を大きく取り返す |
| 🛞 タイヤマネジメント | タイヤ摩耗 -45%。ピット回数が減ることも |
| 🏃 ラストスパート | 残り20%でラップタイム短縮 |
| ❤️ 鉄の心臓 | クラッシュ率 -60% |
| ⚔️ オーバーテイカー | 前車に詰まったときの失速 -55% |
| ⏱️ 予選番長 | 予選の速さ +7% |
| 🔧 マシンフィーラー | マシントラブルによるリタイア -45% |
| 📐 精密機械 | ラップタイムのブレ -55% |
| 💪 アイアンマン | 終盤のスタミナ低下が起きない |
| ✨ 天性のセンス | 総合力が常に +8% |
| 🌱 大器晩成 | 獲得経験値 1.5倍 |

選手権のポイントは動かないので、何を取りに行くかで選びます。

| 特別戦 | 距離 | ねらい |

| 🎪 エキシビションレース | 0.45倍 | ファンが一気に増える。消耗は軽い |
| 🔰 新人テスト | 0.6倍 | ドライバーの経験値が大きく入る |
| 🏆 スポンサーカップ | 0.8倍 | 賞金4.5倍。2年目以降 |
| ⛈️ レインマスターズ | 0.7倍 | 必ず雨。雨に強いドライバーの見せ場。2年目以降 |

### 🛞 タイヤ

3種類のドライタイヤがあり、速さと保ちが逆になっています。

| タイヤ | ペース | 摩耗 | 寿命の目安 |
|---|---|---|---|
| 🔴 ソフト | 最速（-1.4%） | 1.60倍 | 15周 |
| 🟡 ミディアム | 標準 | 1.00倍 | 25周 |
| ⚪ ハード | -1.4%（遅い） | 0.66倍 | 38周 |

雨なら🟢インター、大雨なら🔵ウェットに自動で切り替わります。

**ドライレースでは2種類以上のタイヤを使わなければなりません**（実際のF1のルール）。
同じ銘柄だけで組まれた作戦は、いちばん短いスティントが自動で別銘柄に差し替わります。

**寿命を超えると急激にタレます**（超過周回数の2乗でタイムを失う）。
スタートタイヤは自分で選び、2本目以降は残り周回に合わせて自動で選ばれます。

ライバルは3通りの傾向（攻め／バランス／堅実）とストップ数を持つので、
**ソフトで3ストップの車と、ハードで1ストップの車が同じレースで戦います**。

レース中は全車のタイヤが順位表に表示されます（銘柄＋使用周回数、
寿命が近いと黄色、超えると赤く点滅）。自チームは残量バーつきで表示されます。
ピット作業中の車はピットレーンに停まり、順位表には `PIT` と出ます。

### 🔋 バッテリー（ERS）

**エレクトロニクス**の性能から、容量・1周あたりの回生量・放電量が決まります。
放電すると直線で速くなりますが、電気は無限ではありません。

- 通常走行では回生と放電がほぼ釣り合い、少しずつ減っていきます
- **前の車を2秒以内に捉えると、1.75倍の量を放電して仕掛けます**。
  攻め続けると5周ほどで空になり、そのぶんのタイムを失います
- ストレートの長いコースほど、放電が速さに変わりやすくなります

レース中は自チームのバッテリー残量がゲージで表示されます（残り少ないと赤）。

### 🤝 スポンサーの種類

スポンサーは**もらえるものが違います**。金額の大きさだけで選ぶものではありません。

| 種別 | 内容 |
|---|---|
| 💰 現金型 | 毎戦まとまった資金 |
| 🔬 技術提携 | 資金は少ないが**研究ポイントが大きく入る** |
| 🔀 複合型 | 資金と研究ポイントの両方 |
| 📣 露出型 | 資金は控えめだが**ファンが増える** |

技術提携で固めれば、資金は苦しくても開発だけは進みます。
現金型で固めれば設備と人材に投資できます。実測（マーケLv5・注目度70）：

| 構成 | 資金/戦 | 研究P/戦 | ファン/戦 |
|---|---|---|---|
| 現金型3社 | +20,838万 | 0 | 0 |
| 技術提携3社 | +4,342万 | **+351** | 0 |
| 混合 | +25,565万 | +338 | +1,253 |

目標達成ボーナスは**契約上シーズン3回まで**です（勝ち続けても青天井にはなりません）。

### 💹 収支

「📖情報」の先頭に収支が出ます。

- **毎週の支出**：スタッフ給料／首脳陣の報酬／ドライバー給料／育成費／施設維持費／その他
- **レース1回あたり**：スポンサー収入 −（4週ぶんの支出）＝ 差し引き

ここに賞金が加わるので、差し引きがマイナスでも上位に入れば黒字になります。
逆に言えば、**勝てないのに人を増やすと破綻します**。

### 👥 スタッフと首脳陣

人事画面は「ドライバー／育成／スタッフ／首脳陣」の4つに分かれています。

**現場スタッフ**は技能を持ち、職種ごとの合計が効果になります。
画面では一人ひとりの技能バーと、職種ごとの厚みが見られます。
**チームの規模が大きいほど、腕の良い人材が応募してきます**
（ガレージチームなら平均技能18、伝説のチームなら49）。

**首脳陣**は4つの役職に1人ずつ。効果はすべて実数で効きます。

| 役職 | 効果 |
|---|---|
| 👔 チームプリンシパル | スポンサー収入 +0.6%／技能1、注目度 +0.4%／技能1 |
| 🔬 開発責任者 | 開発の伸び +0.8%／技能1、設計のレアリティ抽選に加算 |
| 🔧 ピットクルーチーフ | ピット停止 -0.06秒／技能1、信頼性 +0.15／技能1 |
| 🚚 ロジスティクス責任者 | 週の固定費 -1.0%／技能1（最大35%） |

ロジスティクスは**大所帯ほど効きます**（週の固定費が511万なら-81万、1905万なら-587万）。
報酬は高いので、規模が小さいうちは無理に置かない選択もあります。

### 🏠 本拠地を歩く

メイン画面の主役は**チーム本拠地**です。プレイヤー（チームプリンシパル）が
敷地を歩き、建物の入口に立つと、その設備へ入れます。

| 操作 | |
|---|---|
| 矢印キー ／ WASD | 歩く |
| 画面をタップ／クリック | そこまで歩いていく。**建物を押すと、歩いていってそのまま入ります** |
| Enter ／ スペース ／ 「入る」ボタン | 目の前の設備へ入る |

| 建物 | 入ると |
|---|---|
| 🏭 ファクトリー | 開発 |
| 🌀 風洞 | 研究 |
| 🏛️ シミュレーター | 練習 |
| 📣 マーケティング室 | 営業 |
| 🎓 ユースアカデミー | 育成 |
| 🔧 ピット設備 | 整備 |

**休養だけは建物に割り当てていません。** 押した瞬間に1週進んでしまうので、
歩いている途中の誤操作で週を失わないようにしています。建物から開く画面は
すべて確認を挟むため、入っても週は進みません。

背景は一度描いたものを取っておき、毎フレームはキャラだけを重ねています。
レース観戦中と、画面（モーダル）が開いているあいだは歩行を止めます。

### 🔋 バッテリー（車体開発）

車体の開発項目に**バッテリー**があります。育てると電気の容量と放電量が増え、
直線での伸びが変わります（例：0→8 で容量 72→80、放電 21.7→23.5）。
冷却も回生量に効きますが、バッテリーのほうが直接効きます。

### 🧠 ピット戦略

**チームごとに作戦の性格が決まっていて、シーズンを通して変わりません。**
対戦を重ねると「あのチームは引っ張る」「あそこは3ストップで攻めてくる」が読めます。

| 性格 | ストップ | 1回目の時期 | タイヤ | アンダーカット |
|---|---|---|---|---|
| 🔥 強気 | +1 | 早め（10%前倒し） | 柔らかめ | よく仕掛ける |
| 🛡️ 堅実 | −1 | 遅め（10%引っ張る） | 硬め | ほとんど仕掛けない |
| ⚖️ 標準 | 素直 | 標準 | バランス | ときどき |
| 🎲 型破り | 毎回変わる | 毎回変わる | 毎回変わる | よく仕掛ける |

**プレイヤーは作戦画面でストップ回数とタイヤの狙いを選べます。**
「おまかせ」ならコースとマシンの摩耗から自動で決まります。

**アンダーカット**：前の車に2.6秒以内で詰まっていて、抜きにくいコースで、
自分のピット予定が3周以内に迫っているとき、1周早く入って新しいタイヤで
前に出ることを狙います。仕掛ける確率は性格で変わります。

### 👀 パドックでの交流

パドックには**人**と**他チームのガレージ**があります。
ガレージ寄りに立てばガレージが、通路側に立てば人が相手になります。

| 相手 | できること |
|---|---|
| 👀 他チームのガレージ | **マシンを覗いて研究ポイントを得る**。自分より速いマシンほど学べる量が多く、分析担当を雇うとさらに増える。1チームにつきレースウィークごと1回 |
| 🧑‍✈️ 自チームのドライバー | 話しかけると気持ちが聞け、調子が上がる。ひとり1回 |
| 📰 記者たち | 取材に答える。強気に出れば注目度が大きく動くが、**下位のうちは大口を叩いても響かない**（効果が半分以下になる） |

偵察は「自分より速い相手から学ぶ」形なので、弱いうちほどよく効きます。

### ⚔️ 追い抜きの攻防

0.55秒以内まで詰めると仕掛けます。コースの性格で戦い方が変わります。

- **ストレートで刺す** — 直線の長いコースで起きやすい。バッテリー残量とスリップストリームが効く
- **コーナーで飛び込む** — 腕とマシンのコーナー性能がものを言う。失敗すると**コースを外れかけてタイムを失い、タイヤも傷む**
- **守る** — 「勝負強い」ドライバーは簡単には譲らない

抜きやすさはコースで大きく変わります（計測値：市街地 26.7回／レース ↔ 高原 68.5回／レース）。

### 🔌 パワーユニットの供給

エンジンは**自前で育てる**か、**強いチームから買う**かを選べます。

- 買えば一気に速くなる（例：自前10 → アルジェント製35）
- ただし**供給中は自分で開発できず**、毎戦の供給料がかかる
- 契約を切ると自前のパワーユニットに戻る。**同じシーズン中の解約は違約金**

小さなチームが一足飛びに戦えるようになる代わりに、自力で伸ばす道を一時的に捨てる選択です。

### 🏁 パドック（レースウィーク）

レースウィークになると、拠点の代わりに**サーキットのパドック**を歩きます。
操作は本拠地と同じです。

| 場所 | 入ると |
|---|---|
| 🏎️ 自チームのガレージ | マシン（装着・合成） |
| 🧑‍✈️ ドライバーの控え | ドライバー |
| 📊 タイミングブース | 情報（順位・収支） |
| 🏁 コースへの出口 | レースへ向かう |

ガレージはチームごとに並び、自チームだけシャッターが開いて中で整備中の
マシンが見えます。ピットウォールのボードや屋根の帯は各チームの色です。

### 🎨 見た目（2種類）

トップバーの 🌙 / 🎨 ボタンで、いつでも切り替えられます（選択は保存されます）。

| | HD-2D（初期設定） | カイロ風 |
|---|---|---|
| 画面 | 暗い舞台に金の枠が浮かぶ | 生成りの紙にこげ茶の太枠 |
| コース図 | 夜の路面。セクター線が光る | 芝の上の見取り図 |
| レース | 光・ボケ・粒子つき | 素直なドット絵 |
| 本拠地 | 夕暮れ。窓に明かりが灯り、建物が影を落とす | 昼 |

**HD-2D側で足しているもの**（オクトパストラベラー風の絵作り）:

- **ブルーム** — 明るい所だけがにじんで光る。同じ絵を `multiply` で重ねて
  色を4乗し、暗い色を沈めてから、ぼかして加算している
- **被写界深度** — カメラが寄るほど、見ていない所がぼける。ジオラマらしさが出る
- **落ち影** — 建物や木のシルエットを黒くして、光の向きへずらして重ねる。
  形に沿った長い影になる
- **色調** — 影側を紫に沈め（`multiply`）、そのうえで明暗差を立てる（`overlay`）
- **粒子** — 火花・砂ぼこり・雨の水しぶき
- **周辺減光** — 四隅を落として中央に目を向けさせる

追加ライブラリは使っていません。canvas 2D の `filter` と合成モードだけです。
`filter` が使えない端末（Safari 14 未満など）では、拡大縮小のにじみで代用し、
落ち影と被写界深度は自動で省かれます。

### 🎬 レース観戦

再生速度は **🐢とてもゆっくり／▶ゆっくり／▶▶ふつう／▶▶▶はやい／⏱実時間** の5段階です。
**実時間**は実際のレースと同じ速さで進みます（24周でおよそ35〜40分）。

**カメラ**が3モードあります。

- 🎬 **おまかせ** — 自チームが誰かと2.2秒以内で競っていればそのバトルに寄り、
  いなければ首位争いを追う
- 🚩 **自チーム** — 自分の2台を収める
- 🗺️ **全体** — コース全体を俯瞰

寄ると車が大きく描かれ、コーナー名も読めるようになります。
最終ラップには **FINAL LAP**、ゴール時にはチェッカーフラッグが振られます。
ピット作業中はクルーが4輪に付き、残り時間がカウントダウンされます。

### 📝 契約更改

シーズンが明けると、**活躍した人ほど報酬を要求します**。
チームが大きく、順位が良く、ファンが多いほど要求は強くなります
（優勝チームで週の人件費 +22%、最下位で +12%）。

勝ち続けると維持費が重くなるので、**強くなっても経営から解放されません**。

### 🏆 チャンピオンシップ

配点は**実際のF1と同じ** 25-18-15-12-10-8-6-4-2-1 の10位まで。
さらに **10位以内で完走したファステストラップに +1点** が付きます
（10位より下だった場合はボーナスなし）。

「📖情報」を開くと、ドライバーズ／コンストラクターズの両ランキングに加え、
**優勝・表彰台・ポールポジション・ファステストラップの回数**、そして
**ラウンド別の獲得ポイント表**（金＝優勝、緑＝表彰台、× ＝リタイア）が見られます。

### 📣 注目度（メディア露出）

チームがどれだけ話題になっているかを表す 0〜100 の値です。

`🫥無名` → `📻注目され始め` → `📰話題のチーム` → `📺人気チーム` → `🌟主役` → `👑時代の顔`

**上位でゴールするほど上がります。ポイント圏外でも順位が上なら上がります。**

| できごと | 注目度 |
|---|---|
| 優勝 | +16 |
| 表彰台（3位） | +10 |
| 入賞（8位） | +5 |
| ポイント圏外（14位） | +1.8 |
| 最後方（20位） | +0.4 |
| ポールポジション | +3 |
| ファステストラップ | +3 |
| グリッドから順位を上げた | 1つにつき +0.4（最大 +6） |
| リタイア | -2 |

放っておくと毎週 3.5% ずつ風化するので、走り続けないと忘れられます。

注目度は経営に直結します。

- **スポンサー収入が最大 1.6倍** になります（注目度50で ×1.30、95で ×1.57）
- **大手スポンサーは注目度が条件**です。ファンを集めるだけでは相手にされません
- 注目度が高いほど、**向こうから契約のオファーが届く**ようになります。
  オファーには通常より多い契約金が付きますが、4週で引っ込みます

つまり、賞金の出ない11位でも「20位より11位」に価値があり、
最後方から追い上げた一戦がスポンサー契約につながります。

### 🎫 開発チケット

入賞できないレースが続くと、チームに**開発チケット**が届きます
（イージー3戦／ノーマル4戦／ハード5戦の連続ノーポイントで1枚）。
1枚使うと、**開発の「改良」か「設計」を資金も研究ポイントも使わずに1回行えます**。
入賞するとカウントはリセットされます。

苦しいときほど手が止まるのがこの手のゲームの詰みどころなので、
沈んだチームに一手ぶんの余地を残すための仕組みです。

### 🎓 下部組織（ユースアカデミー）

施設の「ユースアカデミー」を持つと、若手を抱えて育てられます。

- 「👥人事」から**若手をスカウト**（アカデミーのレベルで枠が増える：Lv1で1人、Lv10で6人）
- 若手は**毎週すこしずつ成長**します。コマンドを消費しません
- 伸びは **才能★1〜5**（平凡／有望／逸材／天才肌／大器）とアカデミーのレベル、
  トレーナーの技能で決まります
- **21歳までが伸び盛り**。22〜23歳で鈍り、24歳を過ぎるとほぼ止まります
- トップチームのシートが空いていれば**昇格**させられます

アカデミーのレベル別に、1シーズン（48週）育てた場合の総合値の伸び（初期25から）：

| 才能 | Lv1 | Lv5 | Lv10 |
|---|---|---|---|
| ★1 平凡 | 34.9 | 43.7 | 55.7 |
| ★3 逸材 | 40.6 | 54.8 | 73.1 |
| ★5 大器 | 54.3 | 71.6 | 92.1 |

3年目の移籍市場に出る即戦力が総合65〜69なので、
**アカデミーに投資して大器を掘り当てれば、買うより強い**ドライバーが育ちます。

### チーム本拠地

「🏗️ 施設」を開くと本拠地の全景が出ます。**施設のレベルがそのまま建物の姿になります** —
ファクトリーは煙突が増えて大きくなり、ピット設備はガレージのベイが増え、

タイトルを獲るごとにトロフィー像が並びます。

施設・ファン数・タイトル数から **チーム規模** が決まり、画面上部に表示されます。

`ガレージチーム` → `弱小プライベーター` → `中堅コンストラクター` → `有力チーム`
→ `トップチーム` → `強豪ワークス` → `伝説のチーム`

### レースシミュレーションについて

全22台について1周ずつラップタイムを積み上げています。ラップタイムは
マシン性能60%＋ドライバー40%を基準に、タイヤ摩耗・終盤のスタミナ低下・
天候・作戦・ドライバースキル・ランダム要素で変動します。
前車と0.9秒以内に詰まると「ダーティエア」でタイムを失うため、
抜きにくいコースほど団子になり、順位が動きにくくなります。

観戦画面の車の位置は、この積み上げたタイムから逆算して描いています。
画面に映っているバトルは演出ではなく、実際に結果を決めている計算そのものです。

### コース形状が走りを決める

サーキットの形は座標の羅列ではなく、**解析されて実際のルールになります**。

`src/geom.js` がコース形状から曲率を求め、コーナーとストレートを自動で切り分けます。
そこから導かれるものが3つあります。

**1. 追い抜きやすさ** — 最長ストレートが1周に占める割合が、そのまま
ダーティエアの効きに反映されます。モンテローザ市街地（最長ストレート17%・11コーナー）は
実際に抜けず、グリーンヒル・フォレスト（45%）では順位がよく動きます。

**2. マシンごとの速度プロファイル** — 各車について
「コーナーでどこまで減速し、立ち上がりでどう加速し、直線でどこまで伸びるか」を
最高速・コーナー・加速の配分から計算します。同じラップタイムの2台でも、
ダウンフォース型はコーナーで、パワー型は直線で前に出るため、
**1周のあいだに何度も抜きつ抜かれつが起きます**。
高速域ではスピードライン、減速時にはブレーキランプが点きます。

**3. 区間タイム** — 1周は3つのセクターに分けられます（境界は 1/3・2/3 地点にいちばん近い
直線上に置かれます）。各セクターのタイムは、その車の速度プロファイルの配分から算出されるので、
**どのマシンがどの区間で速いのかがそのまま数字に出ます**。
ピットでの停止時間は最終セクターに加算されます。

観戦画面では実際のタイミングモニターのように、セッション最速は紫、自己ベストは緑で
表示されます。前の周のタイムは薄く残るので、3区間すべてを見比べられます。

**4. コースの描画** — コーナー区間には縁石が、最長ストレートには DRS 区間の表示が入り、
スタートラインの手前にはグリッド、その外側にピットレーンとガレージが並びます。
セクター境界には S1 / S2 / S3 の標識が立ち、曲率の急なコーナーにはそのコースの
名物コーナー名（オー・ルージュ、スプーンカーブ、カジノヘアピンなど）が表示されます。
コース外にはテーマに応じた景色が並びます（芝＝木立、市街地＝ビル、砂漠＝ヤシと岩、
ネオン＝電飾看板）。メインストレートのピット反対側には観客席が入ります。
スタート地点は各コースの最長ストレート上に来るよう配置してあります。

レース開始時にはスタートシグナルが5つ順に点灯し、消灯と同時にスタート。
再生速度は「じっくり（約95秒）／ふつう（約40秒）／はやい（約13秒）」から選べます。
ガレージのコース図もセクターごとに色分けされ、名物コーナーの位置が示されます。

ライバルチームもマシンの型を持っています（パワー型・ダウンフォース型など）。
コースとの相性で速さが変わるので、毎戦おなじ顔ぶれが前にいるわけではありません。
